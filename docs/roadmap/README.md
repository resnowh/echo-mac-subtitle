# 历史规划与决策记录

此目录保存 2026 年 9 月形成的桌面与多平台方案，供追溯技术决策。**这里的功能、工期与平台设想不是当前实现状态，也不构成发布承诺。**

当前进度请查阅 [项目首页](../../README.md)、[技术文档](../README.md)、[变更记录](../../CHANGELOG.md) 和 [macOS 发布流程](../release.md)。macOS 是当前主开发平台；Windows 原生预览在独立 [分支](https://github.com/resnowh/echo-mac-subtitle/tree/feature/windows-preview)，移动端尚未实现。

## 阅读规则

- 查**现有实现**：以 `main` 的 macOS 源码、[架构](../architecture.md)、[数据模型](../data-model.md) 为准。
- 查**自动测试**：以 [测试说明](../../tests/README.md) 和 GitHub Actions 实际运行结果为准。
- 查**正式发行条件**：以 [release.md](../release.md) 为准，不引用旧版排期作为当前进度。
- 查**原始思路**：阅读本目录各编号文件；这些文档保留历史原貌，不因实现变化自动重写。

跨平台共用核心、移动端支持、收费、发行渠道等仍需独立决策，历史方案中的选项不代表已确认。
