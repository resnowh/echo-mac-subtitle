# Echo 桌面产品与发布方案：Mac 体验优先

日期：2026-09-16｜版本：v3｜状态：设计提案，尚未实现或实机验证。

## 建议结论

当前目标为 **先完成 macOS、Windows 可安装、可升级的桌面软件，Mac 体验优先级最高**。Android 后续再做；iOS 暂缓，用户目前没有 iOS 手机。首期仍供个人和小范围用户使用，各自填写 API Key，保留正式签名分发目标。

Mac 在现有 Swift/SwiftUI 项目上渐进完善；Windows 推荐 WinUI 3/C# 独立原生实现。先共用数据契约、功能规则和回归样本；Rust 共享代码保留为后续可选方向，不作为首发或 Mac 改造前置条件。首期允许两套实现，以明确契约和双端回归控制差异。

**Mac 的交互、稳定性与数据安全高于代码共用比例。** 当前 Windows 主机用于 Windows 开发和静态检查；Mac 体验验收仍需可用 Mac。无需为当前桌面里程碑购买 iPhone、搭建移动工程或完成移动上架。

## 设计默认值

- 首发验证 Windows 11 x64；ARM64 单独验收后提供。Windows 10 兼容性另列测试范围，不先承诺。
- Soniox 继续负责实时识别与翻译，DeepSeek 继续作为可选总结服务。
- 默认英语识别 → 简体中文翻译，Speaker 开启，总结关闭，不保存原始音频。
- 桌面功能对齐完整原版；先保留当前 Mac 数据格式，Windows 兼容读取。Archive v2 是待评估设计，不强制 Mac 为首发迁移数据。
- 新增 Windows 紧凑字幕模式、设备选择、快捷键和可选后台运行；先保证原版能力，再做这些增强。
- 第一轮建立 Mac 体验基线及 Windows 音频可行性；移动桥接、录音、真机和上架均延后。现有 Mac 应用本轮不改动。
- 首期无 Echo 账户、订阅或云同步后台；本地存档可导入导出，Key 不随存档迁移。

具体系统版本、发布方式及增强功能排序属于可调整设计值，不代表用户已逐项确认。开始实现前可直接在本套文档上修订。
