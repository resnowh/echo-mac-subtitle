# 方案依据与数据清单

调研日期：2026-09-16。此为公开版本；原始网页响应、源码快照、抓取时间/状态和文件哈希保存在本地工作区，不随仓库发布。不包含账号仓库列表、凭据或实际录音数据。

## 当前决策

项目维护者确定：Mac 体验最优先，先完成 Mac/Windows；Android 后续，iOS 暂缓。首期个人/小范围使用，用户自填 API Key。以 [07-Mac优先的桌面实施方案](07-Mac优先的桌面实施方案.md) 为准。
