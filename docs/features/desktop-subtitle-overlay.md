# macOS 桌面悬浮字幕

透明悬浮字幕用于视频、在线课程和跨应用实时翻译。其行为是**普通视频字幕**，不是歌词滚动或逐字高亮。

[返回文档中心](../README.md) · [验收清单](../testing/desktop-subtitle-overlay.md)

## 操作

1. 在 Echo 主窗口右上角打开「悬浮字幕」，启用字幕。
2. 选择「调整位置和大小」。悬浮窗顶部出现**拖动区域**，拖动即可移动；右下角明显的手柄可以同时调整宽度和高度。此模式中仍可滚动过长的文本。
3. 调整完成后，在主窗口菜单选择「完成调整」，恢复日常悬浮模式及点击穿透。
4. 在「悬浮字幕设置」中修改字号、原文与译文颜色、背景不透明度等；修改即时生效，无需重连 Soniox。

如果移动或调整后窗口不可见，可以在设置中「重置位置」；手动调整高度后还可以选择「高度自适应」。关闭点击穿透后，可用鼠标滚动阅读超出窗口高度的字幕。

## 精简的设置

- 常用：启用悬浮字幕、原文/译文开关、**统一字号**（译文比原文略小）、两种文字颜色、**背景不透明度**（默认 0，即透明）。
- 位置与大小：进入/退出调整模式、重置位置、恢复高度自适应。
- 「高级选项」中保留：点击穿透、定稿保留时间、文字透明度、阴影强度。
- 旧设置仍使用 `desktopSubtitleOverlaySettings.v1`，新增颜色、背景透明度、手动高度均为可选字段；原有 UserDefaults 设置保持兼容。恢复外观不会清空已存档字幕。

## 字幕显示规则

- 当前句以 provisional 内容实时更新，不会把修订重复拼接；原文和译文按同一 entry UUID 配对。
- **新句开始时，最近一句继续显示一段时间**（默认 5 秒，可在高级选项调整）；最多保留一条上一句，以免遮挡屏幕。上一句可能晚到的译文只更新它自身，不会替换当前句或误配译文。
- 当前句定稿后也有独立保留时间。停止录音、清空或开始新 session 时清除实时悬浮内容，不删除主窗口和 Archive 中的字幕历史。
- 长句**不再限制两行或截断尾部**。窗口会按内容尽力增高至当前屏幕可用高度约 85%；超过此上限时使用垂直滚动。若启用点击穿透则鼠标事件交给下面的应用，需关闭点击穿透或进入调整模式才能操作滚动。
- 默认无卡片背景；背景不透明度仅改变文字后方的深色圆角底，文字透明度与文字颜色分别控制。

## 架构与验证边界

`DesktopSubtitleOverlayReducer` 保存当前句和最近一句；`DesktopSubtitleOverlayFeed` 只向 AppKit/SwiftUI 发布低频只读字幕快照。唯一透明 `NSPanel` 负责窗口几何和位置持久化，录音、Soniox WebSocket 与 Archive 不受影响，也不会创建第二录音服务。

屏幕/Space/全屏覆盖使用系统允许的尽力实现，无法保证所有受保护或独占全屏应用均可显示。自动化检查覆盖句子切换、翻译晚到、设置读写及纯逻辑；真实多显示器、拖动/缩放手感和长句 UI 仍应在不影响正在录音的 Echo 的独立设备/会话中验收。
