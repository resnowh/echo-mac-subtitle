# Windows A02 本机音频切换验证底稿

- 日期：2026-09-30
- 命令：`dotnet run --project windows/Echo.CoreChecks -c Release -- --audio`
- 环境：Windows 11 家庭版中文版，版本 `10.0.26200`（Build `26200`）；.NET SDK `10.0.401`
- 设备枚举：Render 4 个活动端点、Capture 2 个活动端点。未保存设备名称或 ID。
- 结果：39 项检查全部通过，其中 9 项直接覆盖本机音频和本地模拟 WebSocket。

## 与 A02 相关的记录

1. 播放、麦克风、双输入三种模式均满足 PCM 帧长度检查，重建采集后继续输出数据。
2. 在一个麦克风采集会话中，使用本机枚举到的两个活动输入端点交替切换 20 次；无重连识别 WebSocket。
3. 切换前先向客户端发送临时字幕 `Before`，停止时发送最终字幕 `Before and after.`；最终存档模型中只有一条收敛后的字幕。
4. 无效输入端点切换后，采集恢复到原输入，识别连接继续工作。
5. 本地模拟服务收到了 PCM 和结束标记，并在 Stop 完成前返回最终结果。

此记录仅代表该机当日枚举到的设备与驱动，不覆盖其他硬件组合、物理拔插或蓝牙配置。只向本机模拟服务发送音频帧，没有调用云端、没有保存原始音频，也没有启动 Echo 窗口。
