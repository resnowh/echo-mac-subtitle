# Windows A08 存档跨段 SRT 时间轴验证底稿

日期：2026-09-30
范围：多录音段存档导出的字幕时间顺序与重叠处理。

## 环境与方法

- Windows 11 build 10.0.26200；.NET SDK 10.0.401。
- 在 `Echo.CoreChecks --audio` 中即时构造合成 Archive，并调用生产 `TranscriptFiles.Srt`；未启动 Echo 窗口。
- 输入仅为两条人工合成文本和时间值，无真实录音、设备 ID 或服务端数据。

## 合成输入与观测

| 段落在列表中的位置 | StartedAt | 字幕文字 | 字幕时长 |
|---|---:|---|---:|
| 第 1 项（故意较晚） | 800000002 | later segment | 3 秒 |
| 第 2 项（较早） | 800000000 | earlier segment | 5 秒 |

SRT 输出先列 `earlier segment`，时间为 `00:00:00,000 --> 00:00:05,000`；之后列 `later segment`，由于两段实际时间重叠，其 cue 被推到 `00:00:05,000 --> 00:00:08,000`。测试同时断言内容顺序和两个完整时间区间。

## 结果与边界

- `dotnet run --project windows/Echo.CoreChecks -c Release -- --audio`：48 项全部通过；无云端调用、未保存音频。
- 该检查使用本机代码生成的短小合成 Archive，不代表大存档的内存/性能结果，也不验证第三方播放器对说话人/语言前缀的显示方式。
- 拆段及失败回滚另有核心回归覆盖；真实文件系统故障、很长存档导出和播放器导入仍需验收。

只留存本测试输入、断言和本说明，不包含用户语音或真实字幕。
