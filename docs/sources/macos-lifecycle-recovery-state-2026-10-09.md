# Mac 睡眠/唤醒恢复状态机后台验证

日期：2026-10-09

## 数据与实现依据

- 生产状态机：`macOS/Models/LifecycleRecoveryState.swift`
- 应用事件接线：`macOS/ViewModels/SpeechViewModel.swift` 的睡眠、唤醒和录音恢复处理
- 新增回归：`tests/LifecycleRecoveryChecks.swift`
- 执行入口：`tests/run_stream_checks.py`，由 macOS CI 调用

本测试直接编译并调用生产状态机，不启动 Echo，不触发系统睡眠，不访问麦克风/屏幕音频，不连接云端。测试全程只用内存状态，无外部样本或用户数据；可重复输入保存在 Git 测试代码中。

## 覆盖情形

- 无录音意图时，睡眠/唤醒不会排队恢复。
- 录音意图下连续模拟 10 次睡眠、唤醒、恢复成功，检查每个状态及动作。
- 重复唤醒通知不会重复安排恢复。
- 用户在恢复待执行或恢复进行中停止后，迟到的恢复启动/成功事件不会重新开始录音。
- 未请求恢复时的启动事件、重复启动事件及失败后的迟到成功事件均被忽略。

这些是纯状态机回归，不替代真实 Mac 合盖/唤醒、设备稳定等待、网络重连、字幕续存或用户手动停止的硬件验收。
