# 悬浮字幕验收

本文件区分纯逻辑/构建自动验证与真实 macOS GUI 验收。编译通过不代表面板视觉或 Space 行为已经实机通过。

## 当前自动验证

- **已通过**：纯 Swift 逻辑测试，覆盖 provisional 整条替换、不重复拼接、译文延迟到达、原译文 entry 配对、新句不继承旧译文、关闭翻译、定稿后保留时间/超时隐藏、新字幕替换和清空。
- **已通过**：UserDefaults 默认值、配置往返持久化、超范围值回退、至少保留一种语言显示。
- **已通过**：现有隔离音频/传输/Archive/SRT/识别/分段回归测试；未连接真实麦克风、ScreenCaptureKit 或 Soniox。
- **待验证**：隔离 Debug / Release Xcode build；结果以本次任务最终报告为准。
- **未自动执行**：关闭/重启或替换正在运行的 Echo、启动 GUI 实例、使用真实音频设备或影响正在录音的测试，原因是保护用户当前运行的 Echo。

## 真实 macOS GUI 验收清单

以下项目尚未由当前自动化验证；需要独立测试环境，并且不能中断用户当前 Echo：

- [ ] 开启/关闭悬浮层；主窗口最小化、遮挡及关闭（进程仍运行）时持续显示；退出 Echo 后正常销毁。
- [ ] provisional 内容连续修订不闪烁、不重复；先出现原文、延迟译文仍对应同一句；语言切换只影响新 session。
- [ ] 当前句切换到下一句时上一句至少显示默认 5 秒，最多显示一条上一句；旧句译文晚到不会错配到新句；连续快速说话时不会累积无限字幕。
- [ ] 翻译关闭、原文/译文显示选项切换、手动纠正当前句。
- [ ] 定稿后默认 5 秒隐藏；保留时间设置生效；停止录音立即清除，主窗口历史仍在。
- [ ] 通过顶部拖动区域移动；右下角 36pt 手柄同时缩放宽/高，拖动方向正确，完成调整后可再次进入调整；点击穿透时下方应用鼠标操作正常。
- [ ] 中英文、日文和超长字幕完整换行，无任意两行截断；内容过长时自动增高至安全高度上限，关闭点击穿透后能滚动查看剩余文本。不同字号、两行历史叠加、不同屏幕分辨率均不溢出。
- [ ] 原文/译文独立颜色、背景不透明度、文字不透明度修改即时生效；旧版设置与恢复默认值正常，旧 Archive 不受影响。
- [ ] 外接屏拔出/分辨率变化后回到可见区域；多个 Space 与全屏应用覆盖（仅尽力支持）。
- [ ] 连续运行数小时后观察内存、CPU、窗口/任务是否有累积。
